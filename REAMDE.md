## Описание:

Проект "Курсовая работа №1 SkyPro" - это выполнение задач на языке Python в рамках курсовой работы курса "Python разработчик"

На текущий момент в проекте есть следующая функциональность:
  
1. get_greeting - Функция определения приветствия.
2. read_excel_by_date - Функция считывает Excel-файл по дате. Если даты нет, берет текущую.
3. calculate_cards - Функция считающая сумму и кэшбэк.
4. top_transactions - Функция возвращает топ транзакций (по умолчанию 5) по абсолютной сумме платежа.
5. read_json - Функция читает json файл. Если есть ошибки, то выводит пустой файл.
6. get_currency_rates - Функция возвращает курсы валют из списка user_currencies относительно base валюты.
7. get_stock_price - Функция возвращает цену акций из списка user_stocks относительно валюты RUB.
8. structure_data - Функция для страницы "Главная". На вход дата в формате YYYY-MM-DD HH:MM:SS. Выводит структуру, согласно заданию №1 курсовой работы.
9. cashback_categories - Функция определяющая категории повышенного кэшбэка.
10. spending_by_category - Функция, формирующая отчет по категории.

## Тестирование:

Для тестирования использовался фреймворк pytest.
Если у вас его нет, то скопируйте команду для установки.
```
poetry add --group dev pytest
```
Для проверки покрытия тестами, использовалась библиотека pytest-cov.
Если ее нет, то скопируйте команду для установки.
```
poetry add --group dev pytest-cov
```
Для проверки покрытия тестами используйте команду.
```
poetry run pytest --cov
```
Для формирования отчета об покрытии тестами в формате HTML, используйте команду.
```
pytest --cov=src --cov-report=html
```
где src - пакет с модулями, которые тестируются.
Отчет будет находиться в htmlcov/index.html
